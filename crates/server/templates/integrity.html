How to set a host up
  1. Copy examples/host-checks to the host and run sudo ./install.sh. It adds a clamv user with clamv's container uid (10001), the units and the polkit rule.
  2. Mount the host's /run/dbus/system_bus_socket read-only into the clamv or agent container.
  3. Reports land where clamv already reads them (/var/log/aide/aide.log, /var/log/rkhunter.log).
