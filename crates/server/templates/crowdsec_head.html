Connect CrowdSec

clamv reads CrowdSec's Local API as a watcher, so it sees alerts and decisions and can add or remove bans. Nothing is stored here; a restart reads the LAPI again.

  1. Put a long random password in a file, e.g. openssl rand -hex 24 > crowdsec_pw.
  2. Add the watcher on the CrowdSec host: cscli machines add clamv-webui --password "$(cat crowdsec_pw)" (in Docker, run it with docker exec crowdsec).
  3. Set CROWDSEC_LAPI_URL (e.g. http://crowdsec:8080) and CROWDSEC_PASSWORD_FILE on clamv, then restart it.

Set CROWDSEC_READ_ONLY=true to hide the ban buttons. Deleting alerts needs clamv in CrowdSec's api.server.trusted_ips, so clamv doesn't offer it.
